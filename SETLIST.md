# Set List & Hybrid Arrangements

## Core Gruntry Crunge Set List (v1)

1. **Are You Sure Hank Done It This Way** (Waylon) — Slowed, thick organ, dirty guitars, mournful fiddle
2. **Man in the Box** (AIC) — Swampy southern groove, B3 organ, talk-box as slide
3. **I’m a Ramblin’ Man** (Waylon) — Skynyrd dual-guitar attack + driving organ
4. **Them Bones** (AIC) — Short nasty southern stomper, fiddle stabs, greasy organ
5. **Luckenbach, Texas** (Waylon) — Darker undertone, gospel/Black Crowes piano
6. **Rooster** (AIC) — Stretched, mournful fiddle answering the riff, churchy organ
7. **Good Hearted Woman** (Waylon) — Slow-burn, heavy behind-the-beat groove
8. **No Excuses** (AIC) — Open, twangy, piano, southern-rock lift, fiddle doubling melody
9. **Waymore’s Blues** (Waylon) — Funky, greasy, swirling organ, dirty guitars
10. **Down in a Hole** (AIC) — Dark, spacious, slow southern crawl
11. **Mammas Don’t Let Your Babies Grow Up to Be Cowboys** (Waylon) — Heavier, more dangerous
12. **Would?** (AIC) — Swinging southern main riff, organ + subtle fiddle
13. **Lonesome, On’ry and Mean** (Waylon) — Full Skynyrd mode
14. **Nutshell** (AIC) — Stripped encore: voice, sparse dirty guitar, piano, lonely fiddle

## Possible Set Flow Notes
- Open with something immediate and recognizable (*No Excuses* or *Are You Sure Hank…*)
- Alternate country-rooted and grunge-rooted tracks
- Place the biggest emotional pieces (*Rooster*, *Nutshell*, *Down in a Hole*) in the middle or late set
- Keep at least one stripped / quiet moment near the end
