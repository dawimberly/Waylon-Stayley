# Waylon Stayley

**Gruntry Crunge Music**  
*Y’aint never gonna hear these songs the same again.*

A hybrid of outlaw country and grunge.  
Country songs made dirtier, heavier, and more swampy.  
Grunge songs given twang, space, outlaw attitude, and groove.

**Sonic median**: The Black Crowes + Lynyrd Skynyrd  
**Key textures**: Piano / organ + fiddle when it fits  
**Vocals**: RowanShade vocalist on all synthetic versions (his natural voice, with range that can touch Jodeci, Aaron Neville, Tool, Alice in Chains colors)

**Album working title**: *Sound Plantation*

## Core Arrangement Principles

- **Guitar tone**: Thick, slightly overdriven, with room to breathe (Black Crowes / early Skynyrd territory)
- **Organ / Piano**: Almost always present (B3 or Wurlitzer preferred)
- **Fiddle**: Used like a second voice — mournful, aggressive, or answering the guitar
- **Groove**: Slightly behind the beat, with swing
- **Attitude**: Recorded in a hot, smoky room at 2 a.m.
- **Vocals**: RowanShade vocalist — his voice, full range, serving the hybrid arrangements
